# Login-Vs-Cadastro
Login e Cadastro de Cliente (que envolvem processamento de dados no servidor) é algo que não pode ser feito apenas com HTML.

CSS para estilização (deixá-lo bonito).
JavaScript para interatividade no lado do cliente (como validação de formulário).
Uma linguagem de programação de backend (como Python com Django/Flask, Node.js com Express, PHP, etc.) para processar os dados, interagir com um banco de dados e gerenciar as sessões de usuário.
